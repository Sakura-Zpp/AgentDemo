# ADR-0001：采用 LangGraph Supervisor 与专业工作智能体

- 状态：已接受
- 日期：2026-09-07

## 背景

原 Demo 将检索、报告、图表和外部工具集中在单个智能体中，工具权限过宽，路由不可预测，会话状态也难以独立治理。

## 决策

采用 LangGraph 建立一个确定性 Supervisor，并拆分 `knowledge`、`report`、`utility` 三个模型工作智能体和一个无模型的 `memory` 节点。Supervisor 只做路由，工作节点只持有必要工具。LangGraph Checkpointer 负责短期对话状态，长期记忆使用独立、显式授权的数据生命周期。

## 结果

正向结果：工具最小权限、路由可单测、状态可恢复、故障可持久化，且外部 MCP 失败不会拖垮知识问答。

代价：关键词路由对复杂意图的召回有限；新增职责时必须同时更新路由类型、图节点、测试和运行手册。多实例部署还必须为长期记忆提供共享后端。

## 被否决方案

- 单智能体持有全部工具：实现短，但权限与行为难以审计。
- 由模型自由选择工作智能体：灵活，但 Demo 阶段不利于确定性测试和成本控制。
- 把长期记忆放入对话 Checkpoint：删除、保留期和跨 thread 检索无法独立治理。
